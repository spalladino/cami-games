# cami-games

Tiny games for Cami.

- [`driving/`](driving/) — a top-down driving game steered by tilting a phone like a wheel.
- [`dino/`](dino/) — Dino Detective, a footprint-guessing game (built locally; some artwork is not redistributable, see its README).

The phone controller pages are published with GitHub Pages at https://spalladino.github.io/cami-games/.
